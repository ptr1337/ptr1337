## Peter Jung

**Founder & Lead Developer of [CachyOS](https://cachyos.org)** | Arch Linux Package Maintainer | Germany

Building a performance-optimized Arch-based distribution with custom kernels, sched_ext schedulers, and system-wide optimizations.

---

### What I Work On

**[CachyOS](https://github.com/CachyOS)** - Performance-focused Arch Linux distribution
- Custom kernels with BORE/sched_ext schedulers and performance patches
- Multi-architecture support (x86-64, x86-64-v3, x86-64-v4)
- Hardware detection, system tuning, and gaming optimizations

**Key Projects:**

| Repository | Description |
|------------|-------------|
| [linux-cachyos](https://github.com/CachyOS/linux-cachyos) | Custom kernel with scheduler patches and performance improvements |
| [kernel-patches](https://github.com/CachyOS/kernel-patches) | Curated Linux kernel patches for performance |
| [proton-cachyos](https://github.com/CachyOS/proton-cachyos) | Optimized Proton build for gaming on Linux |
| [scx](https://github.com/sched-ext/scx) | sched_ext schedulers (upstream contributor) |
| [chwd](https://github.com/CachyOS/chwd) | Hardware detection tool written in Rust |
| [CachyOS-Settings](https://github.com/CachyOS/CachyOS-Settings) | System-wide performance settings and configurations |
| [ananicy-rules](https://github.com/CachyOS/ananicy-rules) | Process priority rules for optimal system responsiveness |
| [copr-linux-cachyos](https://github.com/CachyOS/copr-linux-cachyos) | CachyOS packages for Fedora users |
